# 04 - Đa Ngôn Ngữ (i18n) (Client)

## 1. Quy Định Bắt Buộc

- **BẮT BUỘC** sử dụng `next-intl` cho toàn bộ hiển thị văn bản người dùng.
- **KHÔNG ĐƯỢC** hardcode bất kỳ chuỗi hiển thị nào trong JSX (bao gồm placeholder, tooltip, nút bấm, thông báo lỗi validation).
- File ngôn ngữ lưu tại:
  - `src/i18n/messages/vi.json` (Tiếng Việt - Ngôn ngữ mặc định)
  - `src/i18n/messages/en.json` (Tiếng Anh)
- **PHẢI** cấu trúc key theo từng **namespace** nghiệp vụ rõ ràng: `common`, `navigation`, `home`, `product`, `booking`, `cart`, `errors`.
- Khi thêm hoặc sửa key, **PHẢI** cập nhật đồng thời ở **cả 2 file** `vi.json` và `en.json`.
- **PHẢI** có test tự động kiểm tra tính toàn vẹn và đồng bộ key giữa `vi.json` và `en.json`.

---

## 2. Cấu Trúc File Messages Chuẩn

```json
// src/i18n/messages/vi.json
{
  "common": {
    "bookNow": "Đặt thuê ngay",
    "viewDetails": "Xem chi tiết",
    "currency": "đ"
  },
  "booking": {
    "title": "Thông Tin Đặt Thuê",
    "selectDate": "Chọn ngày thuê váy/combo",
    "depositRequired": "Yêu cầu đặt cọc trước {amount} đ"
  }
}
```

---

## 3. Ví Dụ Cụ Thể

### Sử Dụng Trong Component
```tsx
// ❌ SAI: Hardcode chuỗi tiếng Việt hoặc tiếng Anh trực tiếp trong JSX
export function BookingCTA() {
  return <button>Đặt thuê ngay</button>;
}

// ✅ ĐÚNG: Dùng useTranslations với namespace xác định
import { useTranslations } from "next-intl";

export function BookingCTA({ amount }: { amount: string }) {
  const tBooking = useTranslations("booking");
  const tCommon = useTranslations("common");

  return (
    <div>
      <p>{tBooking("depositRequired", { amount })}</p>
      <button>{tCommon("bookNow")}</button>
    </div>
  );
}
```
