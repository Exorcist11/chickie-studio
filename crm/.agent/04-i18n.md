# 04 - Đa Ngôn Ngữ (i18n) (CRM)

## 1. Quy Định Bắt Buộc

- **BẮT BUỘC** sử dụng `react-i18next` cho toàn bộ văn bản hiển thị trên hệ thống quản trị.
- **TUYỆT ĐỐI CẤM** hardcode chuỗi tiếng Việt hoặc tiếng Anh trong code, bao gồm:
  - Tiêu đề cột của `DataTable` (Column headers).
  - Thông báo thành công / thất bại qua Ant Design `message.success()`, `notification.error()`.
  - Nhãn của Form và thông báo validate.
  - Nội dung cảnh báo của `ConfirmModal`.
- File ngôn ngữ lưu tại:
  - `src/i18n/locales/vi.json` (Tiếng Việt)
  - `src/i18n/locales/en.json` (Tiếng Anh)
- **PHẢI** cập nhật đồng bộ cả 2 file `vi.json` và `en.json` khi thêm mới bất kỳ key nào.
- **PHẢI** có automated test chạy kiểm tra đảm bảo 100% keys khớp nhau giữa hai ngôn ngữ.

---

## 2. Ví Dụ Cụ Thể

### Tiêu Đề Cột Bảng & Thông Báo Hành Động
```tsx
// ❌ SAI: Hardcode chuỗi hiển thị tiêu đề bảng và thông báo notification
const columns = [{ title: "Tên trang phục", dataIndex: "name" }];
message.success("Xóa sản phẩm thành công");

// ✅ ĐÚNG: Sử dụng hook useTranslation()
import { useTranslation } from "react-i18next";

export function useDressColumns() {
  const { t } = useTranslation();

  const columns = [
    {
      title: t("dresses.columns.name"),
      dataIndex: "name",
      key: "name"
    },
    {
      title: t("dresses.columns.rentalPrice"),
      dataIndex: "rentalPrice",
      key: "rentalPrice"
    }
  ];

  return columns;
}

// Khi gọi thông báo:
message.success(t("dresses.messages.deleteSuccess"));
```
